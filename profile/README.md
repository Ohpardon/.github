<h1 align="center">Pardon.exe</h1>
<p align="center">没听懂的那一句，变成下一次听懂的开始。</p>

我们是一支学生团队，Pardon.exe 是参加 **安克首届黑客松 · 智能录音赛道** 的项目。

从课堂录音与重点标记出发，通过 AI 转写、词汇与知识卡整理、复习及跟读练习，帮助学习者把「听过」变成「学会」。

本项目以学习与公益探索为目的，属于**非商业学生项目**。

**赛事赞助支持** · Amazon Web Services（AWS）
