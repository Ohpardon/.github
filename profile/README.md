<h1 align="center">Pardon.exe · 啪懂</h1>
<p align="center"><strong>Pardon? Tap! Oh, I get it!</strong></p>
<p align="center">刚刚没听懂？按一下，练到真正听懂。</p>

我们是一支小型的学生团队，大家合力开发 Pardon.exe 参加 **安克首届黑客松 · 智能录音赛道**。

**Pardon.exe · 啪懂** 是面向真实英语场景的 AI 听力学习助手，围绕 soundcore 智能录音设备的录音与标记交互展开设计：捕捉「刚刚没听懂」的瞬间，将真实语音片段整理成可反复练习的个性化学习内容。

### Hear → Tap → Learn

- **Hear · 在真实场景里听**：从课堂等英语场景中，积累有上下文的真实语料。
- **Tap · 留下没听懂的瞬间**：轻按标记（Mark），留下值得回听的位置，继续专注当下。
- **Learn · 把片段变成学习卡**：通过 AI 转写、词汇与表达整理，结合原音回听、复习和跟读，逐步练到听懂。

> 用说出 “Pardon?” 的那个瞬间，成为未来说出 “Oh, I get it!” 的起点。
